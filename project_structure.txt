# SOURCE OF TRUTH: MICROSOFT OUTLOOK SECURITY CENTER
# VERSION: 2.4.0 (Advanced Forensic Edition)
# TARGET: AI AGENT / SENIOR DEVELOPER HANDOFF

## 1. PROJECT MISSION
To provide a client-side, non-blocking "Security Sidecar" for Microsoft Outlook that implements real-time heuristic scoring, forensic auditing, and redundant data cleanup without relying on external server-side processing for primary decisions.

## 2. CORE ARCHITECTURE
- **ELECTRON (Main Process):** Manages window lifecycle, secure storage (DPAPI), and provides an IPC bridge.
- **ELECTRON (Renderer Process):** High-performance dashboard utilizing Vanilla JS and CSS for zero-latency UI updates.
- **POWERSHELL (Security Engine):** A non-blocking background worker that communicates with the Outlook Object Model (COM) to perform deep inspection and mailbox management.

## 3. DATA PERSISTENCE (ELECTRON-STORE)
- `config.json`: Stores user preferences (Security Level, Whitelist, Blacklist, API Keys).
- `data.json`: Stores historical scan results, processed EntryIDs, and forensic counters.

## 4. SECURITY PIPELINE (THREAT INTELLIGENCE)
The system implements a three-tier defense strategy for spear-phishing and malware detection:
1. **OFF (Level 0):** Local heuristics only. No external hashes are transmitted.
2. **SMART (Level 1 - Default):** If local heuristics flag an email as suspicious (Score < 65%), the system generates SHA-256 hashes of the body and all attachments. These hashes are sent to authorized Anti-Malware APIs for real-time verification.
3. **MAX (Level 2):** Every incoming email undergoes mandatory SHA-256 hashing of body and attachments for immediate external API verification, regardless of the initial score.

## 5. FORENSIC AUDITING
The system performs deep inspection on incoming emails:
- **Heuristic Scoring (0-100%):** Points based on DMARC/SPF/DKIM alignment, IP reputation, and keyword analysis.
- **SHA256 Fingerprinting:** Every analyzed email has its Body and Attachments uniquely hashed.
- **On-Demand Cloud Scan:** Manual trigger to verify link reputation and file signatures against global malware databases.

## 6. DUPLICATE DETECTION & CLEANUP
A high-performance discovery engine that probes mailboxes for redundant data:
- **Pre-Scan Discovery:** Probes each PST/OST/Mailbox for total size (MB/GB) and email count before starting.
- **DNA Matching:** Identifies duplicates based on a combination of Sender, Subject, Timestamp, and Body Fingerprint.
- **Persistent State:** Discovery results and scan progress are maintained even if the UI menu is closed.
- **Batch Cleanup:** Secure permanent deletion of identified redundant copies with full user confirmation.

## 7. VERDICT ROUTING
- **MALICIOUS:** Confirmed Malware/Phishing -> **Deleted Items**.
- **SPAM:** High-score suspicion -> **Junk Email**.
- **SUSPICIOUS:** Moderate score -> UI Dashboard listing.
- **SAFE:** Whitelisted or Low-score -> **Inbox**.

## 8. PROJECT FILE MANIFEST
- `main.js`: Main application entry point and IPC server.
- `index.html`: Dashboard UI structure.
- `preload.js`: Secure IPC context bridge.
- `outlook-scanner.ps1`: PowerShell-based security engine and COM worker.
- `ui_*.js`: Modular UI logic (List, Settings, Forensics, Duplicates, etc.).
- `logs/`: Directory for security logs and engine output.
- `logs/forensics/`: Storage for zero-disk forensic JSON snapshots.
